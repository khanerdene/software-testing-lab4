### Дүгнэлт
Энэ лабаар Java хэл дээр аливаа классын методуудыг ажиллуулж, тест бичиж, туршилт хийн гаралт зөв болохыг шалгаж сурав. 

Тестуудийг бичсэн методууд нь энэ хичээлийн дүнгээ шалгах зориулалттай байсан ба, letterGrade()-г алдаа шалгагчаар эхлүүлсэн энгийн if-else statement-уудаар хэрэгжүүлж, totalScore()-г for loop-ээр алдааг шалгаж, дээд талын утгуудтай харьцуульж, сүүлд нэмсэн.

Нэгж тестуудийг бичсэнээр хөгжүүлэлтийн үед алдаатай код бичих үед хаана, хэзээ, яаж алдаа гаргасаныг хурдацтайгаар олох боломжыг олгохыг сурав. Мөн нэмэлтээр тестийг хангалтгүй хэмжээнд, эсвэл буруу логиктой бичин дандаа pass болгох нь хөгжүүлэлтэд саад болохыг мэдлээ. Нэгэн сонирхолтой хэсэг нь методыг зориудаар буруу утгатай аргументтэй дуудаж, ямар хариу үйлдэл гаргахийг ажиглаж, түүнд тест бичиж, дараа нь хариу үйлдлийг тодорхойлох явц байлаа.

Мутацын туршилтыг хийхдээ эхлээд тестуудыг ажиллуулж, бүгд давсан байв. Түүний дараа `score >= 90`-г `score > 90` гэж өөрчлөн бичсэний дараа 90 оноо өгөхөд "A" дүн хүлээж байсан тестүүд "B" гэж авч унан, зөв ажиллагаа явагдаж байгааг үүгээр батлав.
